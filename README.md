## About / Über

### 🇩🇪 Deutsch

**Now Playing Overlay** ist eine kleine, klickdurchlässige "Now Playing"-Anwendung für Windows 11, die aktuelle Musikinformationen anzeigt – wie du sie von Windows 10 kennst. Die App läuft minimalistisch im Systemtray und zeigt Titel, Interpret, Albumcover, Quell-App und Wiedergabestatus an. Das Overlay ist vollständig transparent für Mausklicks, sodass Spiele und andere Anwendungen nicht beeinträchtigt werden.

**Hauptfunktionen:**
- ⚙️ Einstellungen im Systemtray (kleines Dreick/Pfeil Symbol unten rechts in der Taskleiste)
- 🎵 Echtzeitanzeige von Musikmetadaten
- 🎨 Albumcover-Anzeige
- 📱 Quell-App-Anzeige
- ⏸️ Wiedergabestatus und Fortschrittsanzeige
- 🖱️ Vollständig klickdurchlässig – nichts blockiert deine Eingaben
- ⚙️ Autostart-Option
- 🌍 Mehrsprachig unterstützt

---

### 🇬🇧 English

**Now Playing Overlay** is a minimal, click-through "Now Playing" application for Windows 11 that displays current music information – just like on Windows 10. The app runs discreetly in the system tray and shows track title, artist, album cover, source app, and playback status. The overlay is completely transparent to mouse clicks, so games and other applications are never interrupted.

**Key Features:**
- ⚙️ Settings in Systemtray (small Triangle-Arrow in the Taskbar)
- 🎵 Real-time music metadata display
- 🎨 Album cover display
- 📱 Source app indicator
- ⏸️ Playback status and progress bar
- 🖱️ Fully click-through – never blocks your input
- ⚙️ Autostart option
- 🌍 Multi-language support
